# Hyprland & end-4 Dotfiles Backup

Preserved backup of Hyprland, end-4 / illogical-impulse configs, and desktop environment components from Arch Linux.

### Preserved Components
- `hypr/` (Hyprland compositor configs, keybinds, rules, idle, lock)
- `kitty/` (Kitty terminal styling and scripts)
- `fish/` (Fish shell configs and functions)
- `darklyrc` (Darkly Qt/KDE theme configuration)
- `waybar/`, `swaync/`, `wlogout/`, `foot/`, `fuzzel/`, `rofi/`, `quickshell/`, `illogical-impulse/`
